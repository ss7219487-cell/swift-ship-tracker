# 🚚 Swift Ship Tracker

## Salesforce Developer Project

Swift Ship Tracker is a Salesforce-based parcel delivery management project designed to simplify parcel booking, tracking, delivery management, and status updates.

The project uses Salesforce configuration, automation, Prompt Builder, and AgentForce AI capabilities to provide a structured and efficient parcel management solution.

---

## 📌 Project Overview

Swift Ship Tracker aims to provide a centralized system for managing parcel delivery information.

The project focuses on:

- Parcel booking
- Parcel tracking
- Sender and receiver management
- Delivery management
- Delivery status updates
- Process automation
- AI-based assistance

The system is designed for three major user roles:

- Customer
- Delivery Agent
- Admin

---

## 🎯 Objectives

The main objectives of the project are:

- To simplify parcel booking and tracking.
- To manage sender and receiver information.
- To manage delivery information.
- To provide delivery status updates.
- To automate parcel and delivery-related processes.
- To reduce confusion in parcel delivery management.
- To use Salesforce automation capabilities.
- To provide conversational assistance using AgentForce AI.
